## 构建内容

用户在画布配置人工问答及推荐来源，运行到该步骤后从全局待办或运行详情阅读依据并回答，相关路径继续。

## 验收标准

- [ ] 预设问答保存问题、允许选项／自由输入约束、明确的推荐来源及理由；默认不设回答期限。
- [ ] 待办关联真实运行、作用域、任务、Agent／上下文来源、尝试和可回答身份，展示前已持久化。
- [ ] 统一“需我处理”与运行内入口读取同一请求，只有有权回答的用户可见并提交。
- [ ] 用户可跳到相关过程和依据后作答；答案回到对应步骤，不另起一个运行或存为无关消息。
- [ ] 人工等待只阻塞相关依赖，独立分支继续；等待不占满活跃执行配额使其他分支停滞。
- [ ] 服务重启后未决请求及已提交决定仍可读取，完成步骤不重跑；暂停期间可保存决定，取消后不能推进。
- [ ] 同一请求并发或重复提交只产生一次有效决定，已处理状态和冲突可解释。
- [ ] 推荐只能来自明确选定的上游输出，缺少推荐仍允许人工回答，不隐藏调用默认模型。

## 测试决策

真实公共图服务创建两个并行问题，查询待办并分别作答；用真实数据库重建及进程终止覆盖保存／消费边界，验证唯一决定和无关分支继续。
