# 更新日志 — v4.31.4

## 上下文管理

- 添加`Token Budget`上下文管理策略，通过窗口切换取代上下文压缩，以及配套的LLM窗口管理和笔记工具。窗口内原文保存在`data/agent_history/<umo_key>/<window_id>`。子代理仍固定走普通 LLM 压缩。
- ChatUI 的文件引用规则移到 system prompt 末尾，输出格式不再先于身份与能力说明。

## 聊天界面

- 侧边聊天菜单：按钮与菜单之间的间隙改为真实命中区域，菜单不再因鼠标移动而闪烁。
- Agent 浏览器面板：加入浏览器会话轮询，无需手动点击刷新。
- 新增开发者模式：每次模型请求产生一条快照，内容为最终交给模型提供商的 payload，覆盖每一步请求与每次重试/降级。可在ChatUI的“设置”中开启，并在顶部工具栏"Dev"处显示
