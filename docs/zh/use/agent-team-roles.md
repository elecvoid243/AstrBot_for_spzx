# Agent 团队角色模板

打开 **更多功能 → Agent 团队 → 资产 → 角色模板**，点击 **新建角色**。角色模板保存职责与能力需求，不创建成员聊天会话，也不直接启动运行。

资产引用固定角色版本，只有明确编辑引用后才使用新角色版本；已有运行继续使用原快照。角色模板直接创建和配置，无需迁移旧成员。

1. 填写角色名称和说明。在 **职责与提示词** 中输入内嵌职责提示词，或填写人格逻辑槽位并绑定本机人格，选择继承人格提示词。
2. 在 **模型** 中选择决定实际执行器的本机配置档案。内置执行器填写模型逻辑槽位并绑定本机模型；远端执行器使用已配置的远端应用，隐藏未使用的本机模型字段。可声明 `tool_use`、`image`、`audio` 能力，并在 **必需的执行器能力** 中选择恢复、任务工具或结果提交要求；不满足时，预览显示具体字段原因。
3. 在 **工具、技能、知识库** 中选择继承、全部禁用或局部覆盖。局部覆盖时输入逻辑槽位名称并按 Enter，再为每个槽位选择本机资源。逻辑槽位表达定义的需求，本机绑定记录当前机器的资源身份。
4. 在 **实例与执行限制** 中填写实例数、并发数、步骤、迭代、嵌套、工具超时和上下文长度。留空继承。独立单任务运行会冻结有效配置；支持的行为与限制见[工作流说明](./agent-team-workflows.md)。
5. 点击 **预览配置** 查看最终有效值、继承来源和覆盖值。缺失、歧义、已禁用或不兼容资源会显示字段路径；点击路径会展开对应分组，将字段滚动到可见位置并聚焦输入框。修改后需要重新预览。
6. 点击 **保存角色**。允许保存待配置模板；卡片用文字显示 **待配置**。编辑已有模板时点击 **保存新版本**，历史定义和历史绑定均保留。通过 **查看历史版本** 重新打开旧版；以旧版内容编辑并保存仍会创建一个新版本。

内嵌提示词属于可移植定义，预览明确显示可移植提示词内容。人格引用仅声明逻辑依赖，其本机提示词不会嵌入定义。完整资产包的导入导出位于「资产 → 团队／工作流」的资产卡片与工具栏，见[资产工作台](./agent-team-workflows.md)。

工具与技能的可用范围取决于所选配置档案的已启用插件，技能还遵守该档案的运行环境。局部覆盖仍遵守人格的工具与技能允许范围；未显式绑定人格时，这些能力继承配置档案的默认人格。被人格排除的绑定会显示字段诊断，不会被标为就绪。内置工具沿用现有 Agent 主管道中的配置档案可用范围。

文件写入工具同时遵守配置档案的 `provider_settings.file_tool_mode`：`patch`（默认）提供 `astrbot_apply_patch`；`legacy` 提供 `astrbot_file_write_tool` 与 `astrbot_file_edit_tool`。未配置或值无效时使用 `patch`，已明确保存的 `legacy` 仍然生效。local 与 sandbox 运行环境使用同一规则。继承工具时仅选择当前模式的工具组；显式依赖另一组工具时，预览与启动会在对应绑定字段报告不兼容，不会静默换工具或扩大角色允许范围。资源目录会报告各配置档案选中的模式。

配置档案后来修改或进程重启时，已有运行仍保留原文件工具模式。恢复按冻结模式解析能力，同时检查当前资源授权：运行环境或必需工具被禁用时，受影响的任务会阻塞。冻结快照不能恢复已撤销的访问权限；结果不明的工具仍需对账或确认后才能重放。

文件操作还遵守当前的管理员要求与管理员 ID、只读模式、额外写入目录和删除黑名单。这些权限可以拒绝已保存计划中的操作，同时保留原工具组、发送者和快照。即使成员的模型请求已经开始，撤销其管理员访问权限也会约束后续操作。

选择的本机配置档案决定实际执行器。内置执行器绑定本机模型；远端执行器使用该档案中的远端应用，不展示未使用的本机模型槽位。在 **模型 → 必需的执行器能力** 中选择内部调用检查点、原远端运行查询、本机任务与团队工具或显式提交任务结果，再点击 **预览配置**。

预览区区分内部检查点、远端查询与仅外部调用边界，并定位不兼容字段。远端执行器不执行 AstrBot 本机工具、技能与知识库，也不能保证本机 `max_steps`、工具超时和上下文长度覆盖；显式配置这些要求时阻止启动。自主协调者必须支持本机派工工具。缺少远端凭证时定位到配置档案，不显示凭证内容。无法保证的模型级 Token 额度与单次输出上限也会拒绝使用；外层调用步骤限制继续生效。

Dify、Coze 和 DashScope Application 通过其支持的任务或用户输入，接收置于任务前的冻结角色与人格职责说明；远端应用自身的系统指令仍在该服务上配置。

## 旧入口与当前入口

| 原有入口 | 当前入口与用途 |
| --- | --- |
| Agent 团队 → 成员 | 资产 → 角色模板；直接创建和配置角色。 |
| 新建可复用角色 | Agent 团队 → 资产 → 角色模板 → 新建角色。模板独立于旧团队和成员。 |
| 工作流编排、运行监控、历史 | 资产 → 工作流引用固定角色版本，运行与历史查看冻结快照。 |

角色接入新版工作流、调用恢复、人工待办与有界循环的步骤见 [资产与运行工作台](./agent-team-workflows.md)。角色、就绪检查和启动使用同一执行器能力判定。原运行保留冻结的角色版本与有效配置；恢复仍检查当前授权及远端绑定兼容性。

配置预览使用当前本机资源，历史定义不会静默改用默认模型。资源后来被删除或禁用时，重新预览会定位问题。已有运行和恢复行为见工作台说明。

旧入口 **角色模板 → 资产 → 角色模板**。模板标识与运行成员状态分开；编辑模板不会改变已有运行的固定配置。
