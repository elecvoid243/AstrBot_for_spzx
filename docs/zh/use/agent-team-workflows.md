# Agent 团队资产与运行工作台

本文画布和工作台截图来自真实 Dashboard、隔离数据库和受控模型服务的联验。

打开 **更多功能 → Agent 团队 → 资产**：

- **团队**：自主团队由协调者按目标派发任务，成员从预设中创建。
- **工作流**：在画布上安排一个或多个 Agent、控制节点和子资产。
- **角色模板**：保存可复用的职责和本机资源配置，供团队或工作流引用。

## 创建与配置

选择 **资产 → 工作流 → 新建工作流**。填写名称，按需选择默认模型；画布可直接添加 Agent，无需先创建角色模板。选择 Agent，配置任务、职责、配置档案、人格、模型和资源。未选人格表示不使用人格；未单独选模型时使用工作流默认模型。启动前每个本机 Agent 都须解析到允许使用的模型。

也可在 Agent 属性中选择角色模板及其**固定版本**。开启覆盖可替换模板值，关闭则继承；空职责表示清空职责，清空人格表示不使用人格，清空模型则回到工作流默认模型。工具、Skills 和知识库分别继承或完整自定义；自定义为空表示禁用该类资源。模板发布新版后须主动升级引用，已有运行不会自动改变。直接配置可保存为角色模板；新模板不会自动替换当前配置。

选择 **资产 → 团队 → 新建自主团队**，填写名称和默认模型，配置协调者及成员预设。每项可直接配置或引用固定角色版本并覆盖；同一模板可带不同覆盖多次使用。协调者只能创建允许的预设。设置成员上限（含协调者）、并发和成员任务上限；启动时填写目标。可配置最终版本审批及输出契约。

## 草稿、固定版本和试运行

编辑资产及画布布局时自动保存草稿，未保存版本的新草稿也显示在列表中。检查保存状态：失败可重试；冲突时可保留本地内容或主动读取服务器草稿。若固定版本变化引起冲突，核对原基版本和最新版本后选择保留整份草稿并使用所选基版本，或读取最新版本重新编辑；系统不会合并字段。

点击 **保存版本** 校验草稿并生成固定版本。正式运行、聊天授权和新引用使用已保存版本；后续编辑不会改变已有运行的冻结定义、输入及配置。

在编辑器选择 **试运行草稿**，检查显示的草稿修订。工作流可选 **完整流程**、**仅选中节点** 或 **从选中节点开始**；自主团队试运行包含协调者和动态成员。预览列出实际执行步骤及所需输入。范围之外的上游数据可按提示选择**精确历史产物**及版本，或按字段类型填写测试数据；要求固定产物的来源须选择产物。检查后点击 **开始试运行**。

试运行真实调用模型和工具，可能产生费用或外部效果；它使用所选草稿修订，不发布固定版本。运行列表可按 **草稿试运行** 和 **正式运行** 区分，并使用同一运行工作台检查结果。

审批目标和推荐依据必须选择真实产物。孤立的全部汇合、不完整循环或缺少并行前驱的局部范围不能启动；单独测试循环内 Agent 只执行一次，并须提供初始反馈。

## 连接输入、输出和控制路径

在输入节点声明输入，在 Agent 中添加输入引用，选择工作流输入或有依赖路径的上游任务的必填标量字段，并在任务中使用 `{别名}`。连线决定执行顺序，不共享上游对话或工具历史。默认输出是文本；需要结构化数据时定义输出字段和类型。输出节点选择返回结果的任务。删除节点或更改字段后，按保存或启动时的诊断修复失效引用。

画布支持缩放、适配、小地图、撤销重做和自动布局；窄屏可展开工具箱及属性。添加**条件**节点，选择输入或上游必填标量、比较方式及同类型值，连接**成立**和**不成立**出口。**全部汇合**等待所有实际进入的路径成功，忽略跳过的路径；没有路径进入时汇合也跳过。局部失败阻塞依赖它的后继，独立路径仍可继续。

画布可添加已保存的工作流或自主团队作为调用节点：选择固定版本，将每项声明输入映射到工作流输入或上游字段。子调用有独立作用域，只接收明确映射的值；在运行中可进入子作用域查看任务和结果。自主团队协调者只能调用配置中明确允许的固定版本工作流。设置嵌套深度和并发限制，子调用与父运行共享根限制。

### 人工节点和有界返工

添加**人工问题**，填写问题和可选答案；选项留空允许自由输入。可明确选择上游必填字符串字段作为推荐及理由。也可添加**版本批准**，连接产物任务，配置通过和退回路径。审批绑定具体产物及版本；退回需要反馈，不会自动重跑作者。

需要反复审查时添加**有界循环**：选择循环体、退出结果及比较条件、最大轮数，明确将上一轮草稿与评审反馈映射到下一轮输入。每轮保留独立任务和产物；达到上限仍未通过时运行需要处理，不会报告成功。审批某一版本不批准后续修订，修订也不会自动重跑消费者。

人工问题、动态选择和审批默认一直等待。可设置期限并选择继续等待或采用请求创建时已展示的有效推荐；推荐缺失、无效或依据不可用时仍等待人工，不会在期限到达时新调用模型。

## 启动与查看运行

在资产卡片选择 **启动运行**，填写声明输入及团队目标；启动前检查依赖和执行器就绪情况，按提示修复不可用资源或权限。运行使用启动时固定的资产、角色、输入和配置。修改资产只影响之后的版本和运行。

**运行 → 进行中**显示未完成运行；**待处理**集中显示需要关注的运行和 **需我处理** 的人工请求；**历史**可分页查看有权访问的资产运行。在列表选择 **查看运行**。

桌面工作台按任务、过程、待办与产物分栏。选择任务查看保存的模型回复、实际提供的思考、工具过程和产物；可按需加载更早过程、展开模型实际上下文及其装配来源。实际上下文可能被截断或由远端执行器缺省；来源先于插件修改，不保证全部保留在最终请求中。切换执行图可查看只读运行快照和任务状态；子作用域及循环轮次可展开。窄屏使用面板切换查看相同内容。后台刷新会保留正在填写的答案。

![真实运行工作台](/images/agent-teams-live-workbench-zh.png)

等待前驱、配额或人工会显示原因；人工等待只阻塞相关路径。打开待办的 **查看过程** 核对依据，再回答问题。审批须先预览指定版本及文件，再批准或填写反馈退回；如指定版本不可用，先创建该版本，系统不会改用最新版。批准后可导出批准版本及其文件。暂停期间可以保存答案，继续运行后才消费；取消会关闭待办并阻止迟到推进。

关闭或刷新页面不会取消运行；重新打开可读取已保存的过程和结果。运行的所有者权限不因回答待办而授予其他人。

## 恢复和用量

在运行详情可暂停、继续或取消整个运行。暂停停止放行新工作，已发出的外部调用仍可能完成；取消不会撤销已发生的效果。失败任务可在核对冻结输入后 **重试失败任务**，这会创建新的尝试；中断的内置执行器任务可在支持的检查点 **继续同一次尝试**。保存的模型响应和已确定的工具结果会复用；尚未保存的模型请求可能重新发送并产生费用。

工具结果不明时，选择任务并展开 **Agent 执行过程** 中的调用，核对参数、部分输出和外部证据。只有工具明确支持的查询或安全对账才能用于确认；查询仍不确定时保持等待。已在外部核实完整结果或失败时，可记录证据和结果；也可明确请求新的执行，但可能重复外部效果。普通重试不能绕过此决定。远端执行器如支持 **查询原远端运行**，先查询原身份；查不到或状态不明不代表操作未发生，决定新尝试前应检查远端服务。

在资产的 **范围限制** 中按需设置调用步数、成员、循环轮数和 token 等上限；保存新版本后应用于新运行。**运行 → 查看运行 → 用量与限制**显示根运行及子作用域、历史尝试的用量。提供商未报告的消耗显示未知，不等于免费；插件或工具内部未计量的费用不受此处硬限制。估算和并发预留也不能保证绝不超额。达到限制后新调用会停止，已保存的结果和效果仍可查看。

## 从聊天调用和处理待办

1. 请调用者在目标平台会话发送 `/asset whoami`。资产所有者打开资产卡片的 **聊天访问**，粘贴完整返回内容，核对平台、发送者、来源会话和配置档案，再选择 **开放此版本**。授权绑定该发送者、确切会话及固定版本；粘贴内容本身不证明身份或授予管理权限。群聊授权允许最终结果在群内可见。
2. 所有可达角色、允许的成员和嵌套工作流必须使用来源配置档案，并遵守模型、人格、工具、技能和知识库限制。导入资产不会自动授权；撤销访问阻止后续调用和结果投递，已有执行记录保留。
3. 调用者用 `/asset list` 查看授权资产，再按卡片提示发送 `/asset <名称或 ID> | {"输入名":"值"}`。名称不唯一或缺少输入时先澄清；普通聊天不会自动选择资产。使用 `/asset status <运行 ID>` 在原授权会话重新取得已有运行的通知和入口。
4. 打开运行链接并保持页面打开，由**原发起者在原会话**发送页面显示的 `/asset connect <连接码>`。连接仅限本次运行、有效期 30 分钟；到期、刷新或服务重启后重新连接仍处理原运行。链接或连接码不会让其他群成员取得发起者身份。
5. 在受限页面回答同一人工待办或审批其指定的精确产物版本，也可按原会话通知中的指令回答。审批只能查看请求指定版本及其声明的文件；完成后可读取根运行发布的最终结果及文件。所有者的过程、思考、工具记录和资源配置不开放。撤销授权或来源配置档案变化后，已有连接也不能继续读写。

Satori 会话和 Misskey note 会话当前不能唯一保留所需来源身份，不能用于资产调用；Misskey 私聊和聊天室可用。企业微信智能机器人须有可用的原会话响应通道：HTTP 回调模式需关闭仅 webhook 发送并设置非空初始响应；通道过期或重启后，在原授权会话发送 `/asset status <运行 ID>` 取回待发送内容。

## 导入、导出与删除

在 **资产 → 团队／工作流** 选择 **导出资产 JSON**，包包含入口的固定子资产和角色及资源需求，不包含凭证、资源内容、授权或运行历史。在目标实例选择 **导入资产包 → 校验并预览**，逐项选择兼容的本机配置档案、模型、人格、工具、技能和知识库，即使 ID 相同也须选择。缺少资源时先配置，再确认安装。安装完整依赖或整体失败；导入不会安装插件、执行脚本或启动运行。

在团队、工作流或角色卡片选择 **删除**并确认影响。所有版本退出新的选择范围，不能直接启动，已有聊天授权也不能启动；既有固定引用、进行中的运行、历史和产物保留。已有父资产仍可使用原固定引用，但不能新增引用。导出有效父资产仍包含其固定依赖；重新导入对应已删除资产的包会冲突，不会恢复资产。删除无法撤销。

## 旧入口对应

| 旧入口 | 当前入口 |
| --- | --- |
| 团队侧栏、成员、工作流编排 | 资产 → 团队／工作流／角色模板 |
| 新建工作流、新建画布工作流 | 资产 → 工作流 → 新建工作流 |
| 运行监控、独立运行 | 运行 → 全部运行／进行中／待处理，选择查看运行 |
| 旧历史标签页 | 运行 → 历史 |
| 运行详情中的人工问题 | 运行 → 待处理 → 需我处理，或查看运行中的同一待办 |
| 聊天旧运行链接 | 使用原会话的 `/asset status <运行 ID>` 获取受限聊天运行入口；所有者登录后仍可从运行详情查看完整过程 |

旧定义迁移和旧运行检查已移除。新版不自动转换或删除旧 Agent Teams 数据。
