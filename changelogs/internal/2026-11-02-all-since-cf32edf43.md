# 更新日志 — 2026-11-02

接续 [2026-10-13 更新日志](./2026-10-13-all-since-fe5204e97.md)，覆盖 `all` 分支中 `cf32edf43` 之后至 `0000ea172` 的改动。相关提交按最终功能归并，不单列开发、测试及中间方案。

## 新增与改进

- 新增 Agent Teams 多智能体团队与工作流功能。
- 新增多用户 ChatUI，支持独立账户、会话、项目、附件与配置选择，以及账户管理和完整备份恢复。
- 新增宿主文件浏览与聊天文件引用，支持文件预览、编辑、重命名和移入系统回收站。
- 新增工作台网页预览和 Agent 浏览器实时观测，可查看浏览器画面、操作过程，并停止或关闭浏览器会话。
- 完善侧边聊天与分支追问，支持保存和重新打开侧聊、独立配置及可调宽度的面板。
- 新增补丁式文件编辑工具，支持批量修改、预览和回滚，并默认使用补丁模式。
- 内置 `/compact` 上下文压缩、交互式选择和技能引导，减少插件依赖；增加新标签页打开的 Skill 商店入口。
- 完善文件审阅，支持整文件差异、逐行评论和直接发送反馈；优化 Git 变更树、大型差异加载与工作树切换。
- 支持按项目配置文档快捷目录。
- 在聊天输入菜单增加目标任务入口，改进目标进度、完成提示、思考强度与上下文用量展示。

## 修复

- 修复流式回复、历史分页和切换会话时的滚动跳动及阅读位置丢失。
- 改进长对话和工具调用的稳定性，修复上下文压缩、取消与恢复、输出长度控制及工具结果关联问题。
- 修复流式图片回复中的内部标记泄漏，以及部分回复、工具信息在后续消息中丢失或显示顺序不正确的问题。
