# 更新日志 — v4.31.2

覆盖 `all` 分支中 `3ca3f384a` 之后至 `2b673132f` 的改动（2026-11-06 至 2026-11-08）

# 核心

## 跨会话通信

- 新增“Agent跨会话通信”功能：在“设置”-“常规”页面可打开（全局配置）。Agent可向其他会话发送消息、创建新会话、阅读其他会话。同一会话中，来自Agent的消息与用户消息分离。
- 支持跨Astrbot实例的通信：在管理面板“设置”-“安全”页面进行功能启用。在Chat侧边栏“远端连接”可通过密钥单向绑定远端连接；“设置”-“远端会话访问”可对外暴露本机并生成密钥。与"Agent跨会话通信"配套，可实现多机Agent协作通信。
- 每个普通会话可单独选择模型与思考强度，重新打开后继续沿用；侧边聊天保持独立设置。

## 上下文压缩

- 移除“按对话轮数截断”兜底策略，上下文压缩改为只按 token 预算控制。
- 压缩会按工具调用与结果的完整配对选择范围，不会把一次调用和它的结果拆开。
- 较早内容会整理成结构化的检查点摘要，并压缩到设定的目标水位；默认保留比例与旧配置一致。

## 子代理

- 优化Subagent的视觉效果：将Subagent执行过程展示为独立的子 Agent 会话页面，可查看每次调用的详情与配置，避免信息堆砌到主Agent对话中。
- 可为动态SubAgent 设置可用的 MCP 工具策略。

## 沙箱与安全

- 新增Windows ACL沙箱，实现对本地 shell 或 Python 工具的写入控制，防止“只读”或“工作区访问”模式下仍然可以通过运行代码来实现越权写入。
- 回退Windows 本地 shell 默认运行时为 PowerShell。

## 聊天界面

- 优化“goal”和“todo”的视觉效果，统一移入顶栏，todo列表创建时自动展开。
- 优化待追加消息队列的视觉效果。修复追加消息后可能导致消息错位的问题。
- 已发送信息的重编辑卡片改为全宽度，并随内容增高。
- 文件变更支持在侧栏打开，并将“侧边栏、磁盘、文件夹”三个入口合并。
- 聊天正文中的 HTML 代码块渲染支持全屏显示。
- 工作区侧栏默认宽度与聊天区各占一半。输出字号整体下调一档。

- 统一两个项目加载入口（左侧侧边栏项目“+”与聊天框项目chip）的行为。移除AGENTS.md和Codegraph自动初始化。用户可按需手动初始化
- 工作区侧栏的工作树菜单与分支菜单统一外观。

## 更新提醒

- 启动后发现新版本或插件更新时自动弹出提示，可在弹窗内更新 AstrBot 或勾选插件。

## 定时任务

- 在Chat页面添加”未来任务“的快捷入口。
- 投递目标中显示 WebChat 会话标题，可按标题或原标识搜索。

## 修复

- 修复会话消息在拒收、取消或后台创建时可能重复、丢失或顺序错乱的问题。
- 修复侧栏拖动时顶栏滞后或出现接缝，以及深色与浅色主题下按钮、胶囊和会话切换的可见性问题。
- 修复流式回复时切换布局会打断滚动跟随的问题。
- 修复打开思考侧栏或引用侧栏时，会移动当前阅读位置的问题。
- 修正文件工具说明中与实际行为不一致的几处描述。
