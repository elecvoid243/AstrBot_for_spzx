## 构建内容

用户把完整 /asset whoami 返回内容粘贴到聊天访问弹窗，核对自动解析结果后为固定资产版本配置授权。

## 验收标准

- [ ] 用一个完整内容输入区替代平台实例、发送者、UMO、配置档案的逐项复制输入。
- [ ] 解析并校验完整身份字段，显示只读核对结果；格式错误、缺字段或身份不一致时不保存部分授权。
- [ ] 不通过拆分 UMO 猜测发送者，私聊和群聊均沿用实际身份表达。
- [ ] 服务端继续检查配置者的资产管理权限，授权限定具体身份、来源、配置档案和固定版本。
- [ ] 保存、重新打开及实际聊天启动能使用同一身份；粘贴文本不构成绕过权限的证明。
- [ ] 普通授权撤销与无权访问保持既有行为；表单失败可修正，不丢失用户粘贴内容。
- [ ] 中英文说明以完整复制示例解释操作；若接口变化同步生成客户端。

## 测试决策

HTTP／公共授权服务使用真实资产和授权记录验证保存与实际调用范围，组件测试覆盖完整内容、错误内容与只读解析；加入群 UMO 不包含发送者的案例。
