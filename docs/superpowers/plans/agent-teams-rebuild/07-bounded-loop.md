## 构建内容

用户可见地配置循环范围、反馈关系、退出条件和轮数上限，并在运行中进入某一轮查看任务及产物。

## 验收标准

- [ ] 循环以明确的画布结构表达，摘要展示最大轮次和退出／反馈关系，不依赖用户手工理解隐含回边。
- [ ] 实际执行遵守显式进入、继续和退出条件；达到轮数上限仍未退出时停止该路径并说明原因。
- [ ] 每轮任务、尝试、输入与产物具有独立归属，历史不会被下一轮覆盖。
- [ ] 运行任务树或等价入口可选择轮次，看到本轮状态和产物。
- [ ] 图校验拒绝无界循环、悬空反馈和不合法跨作用域引用，UI 可定位问题。
- [ ] 暂停、取消和从现有安全检查点恢复不重跑已确认完成的轮次。

## 测试决策

扩展已有循环与真实进程重启先例，验证两轮后退出、耗尽上限、取消、按轮输入与固定产物读取；循环运行不依赖伪造页面状态。
