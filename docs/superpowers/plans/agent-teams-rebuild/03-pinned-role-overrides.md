## 构建内容

用户在工作流 Agent 中选择角色模板、覆盖少量配置、主动升级版本，并将直接配置的 Agent 保存为模板复用。

## 验收标准

- [x] 模板引用固定角色身份与版本，实际运行按该版本及当前节点覆盖计算；模板产生新版本不自动修改工作流。
- [x] UI 提示存在新版本，由用户主动升级；未覆盖字段采用新模板，本地覆盖保持。
- [x] 人格、模型、职责等覆盖来源清楚，清空与未覆盖可区分。
- [x] 工具、Skills、知识库分别选择继承或完整自定义列表；空列表全部禁用，不与模板作增减项合并。
- [x] 直接配置 Agent 可保存为角色模板，再被另一个节点引用；不要求先创建模板才能编辑或运行。
- [x] 升级、撤销编辑和再次读取都保留正确的版本／覆盖关系；运行冻结配置不随升级变化。
- [x] 归属、不可用角色版本及资源诊断在公共接口和 UI 中一致。
