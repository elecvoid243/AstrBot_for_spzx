# 工作流对齐参考产品的能力，沿用 AstrBot 原生资产格式

工作流编辑、类型化数据流、控制路径、试运行、版本和组件扩展应能覆盖与参考产品等价的场景。发布和导入使用 AstrBot 原生资产格式，连接器通过 AstrBot 扩展接口进入，保留既有固定版本、资源映射与权限语义。Langflow 的 JSON 和第三方组件包具有自己的执行与依赖契约，因此本轮验收以等价流程可完成为准。

自定义可执行组件由管理员安装的 AstrBot 插件提供，并声明输入、输出和资源权限。画布可以引用和配置已注册组件。这样的部署边界使工作流定义和资产导入保持可审查，也使组件代码服从 AstrBot 的插件管理。
