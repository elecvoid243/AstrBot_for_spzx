# 单任务工作流资产与独立运行

打开 **更多功能 → Agent 团队 → 工作流资产**。先在 **角色模板** 中保存一个已就绪的角色，绑定支持工具调用的本机模型，并选用内置 Agent 执行器。

1. 点击 **新建工作流**，填写名称，选择角色模板及其版本。
2. 在 **必填输入** 中填写逗号分隔的输入名称，例如 `topic`。任务正文可用 `{topic}` 引用该输入；文字中的大括号需要成对双写以转义。仅支持声明的简单占位符。
3. 点击 **保存新版本**。保存只创建定义，不创建成员会话。编辑资产会新增不可变版本，已有运行保持原版本。
4. 在资产卡片点击 **启动运行**，填写所有必填输入。缺失输入、资源已删除、禁用或不允许访问时会显示字段路径，系统不会换用默认模型或人格。
5. 启动后打开 **独立运行 → 查看运行**。页面展示资产版本、运行成员、执行尝试、只读运行快照以及已提交的完整文本结果。展开 **固定的有效配置** 和 **已保存的成员过程** 可查看本次执行数据。

每次运行创建新的成员身份和独立会话。运行冻结角色、输入、人格提示词及有效配置；运行中的工具纠错沿用同一成员上下文。后续编辑模板只影响新的运行。

Agent 必须调用 `submit_task_result(text)` 提交非空文本。普通回复不会完成任务；未显式提交时显示 **等待显式结果**。有效提交先保存意图，执行到已保存的安全点后才一致地写入结果和完成状态。运行结果保留完整文本，不从最后一条自然语言回复推断。

切换或关闭页面不会停止核心执行。刷新带有 `workflow_run` 参数的地址会重新读取该运行，也可从独立运行列表重新打开。核心进程重启时，已保存安全点的有效结果意图会自动幂等收尾，其余未完成执行会标记为 **已中断，未重跑**。本路径暂不恢复模型响应检查点或重跑未完成任务；未到安全点的结果意图保持待处理状态。

## 新旧入口对照

| 原有入口 | 当前用途 |
| --- | --- |
| Agent 团队 → 成员、工作流编排、运行监控、历史 | 保留旧团队的长期会话和运行入口。 |
| 保存可复用的单任务工作流 | Agent 团队 → 工作流资产；定义不依赖旧团队。 |
| 启动、查看新版单任务运行 | 工作流资产 → 启动运行，然后在独立运行中查看。 |
| 编辑模板与检查运行配置 | 工作流资产编辑新版本；独立运行只显示被冻结的快照。 |

本路径仅交付一个角色执行一个任务及默认文本结果。自定义输出契约、结构化制品、实时事件工作台、调用检查点恢复和团队编排由后续任务交付。
