# Agent Teams run controls in Chat

- Chat shares Bot's whole-run pause, continue, cancel, and failed task retry. In Chat, Cancel run moved from beneath the conversation heading to Inbox & artifacts → Whole run controls.
- Run again starts a new conversation with the completed run's fixed asset version and inputs. The original conversation and artifacts remain available for comparison.
- The Chat conversation list can show only workflow runs, including runs on later pages.
- The Chat sidebar scope switch sits on the **This instance** row as two icons. **Chats** and **Workflow runs** are exclusive categories: neither scope contains the other, and workflow member storage never appears in either.
- Workflow canvas ports show required fields and defaults. Publication reports incompatible structured connections and data cycles at the corresponding input port.
