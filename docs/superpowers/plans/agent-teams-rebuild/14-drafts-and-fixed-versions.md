## 构建内容

用户编辑角色、工作流或自主团队时自动保存草稿，刷新可继续；只有主动保存版本才改变可供引用的定义。

## 验收标准

- [x] 三类资产均有持久草稿与可见的保存中、已保存、失败及冲突状态。
- [x] 刷新重新读取草稿，异步保存的迟到响应不会覆盖更新内容或把失败标为已保存。
- [x] 并发编辑使用修订检查并给出可操作冲突反馈，不静默覆盖其他更新。
- [x] 保存新版本固定草稿内容，已有版本、角色引用和已启动运行的冻结配置不变。
- [x] 聊天绑定和普通正式启动使用明确已保存版本，不能误把未保存草稿当成发布定义。
- [x] 拖动节点或修改表单只更新草稿，不自动制造一系列固定版本；不新增版本发布审批。
- [x] UI、公共接口、持久化和资源校验使用一致草稿／版本语义。
