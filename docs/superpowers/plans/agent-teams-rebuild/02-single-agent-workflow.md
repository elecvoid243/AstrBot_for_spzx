## 构建内容

用户从统一工作流入口进入单 Agent 画布，配置职责、任务和资源，保存固定版本并完成一次真实管线运行。

## 验收标准

- [x] 自主团队与工作流是两种创建意图，不再提供普通工作流／画布工作流两个并列入口；角色模板单独作为可复用资产。
- [x] 新建工作流直接打开含输入、一个 Agent 和输出的画布；Agent 不依赖预先创建的角色模板。
- [x] 工作流明确指定默认模型，Agent 可单独覆盖；未选人格时不套用聊天或配置档案默认人格。
- [x] 实际执行组合人格、职责和当前任务，配置资源到达执行管线；既有权限、用量、检查点及结果提交约束保持有效。
- [x] 默认输出文本，固定版本启动产生可读取的运行结果与产物；保存后重新打开的配置与实际执行一致。
- [x] 沿用 Vue Flow 的选择、拖动、缩放、定位及撤销／重做，节点侧栏编辑不把简单任务送回独立旧表单。
- [x] 资产导航与页面结构采用已讨论的易用方向；后台刷新不闪回其他入口或清空当前编辑选择。
- [x] 使用新格式集成分支，不引入旧单任务定义转换器；必要接口、客户端及入口说明随本票更新。
