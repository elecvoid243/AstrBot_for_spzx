## 构建内容

用户从选中 Agent 的一次模型调用进入上下文详情，核对它实际看到的人格、职责、任务、上游内容、知识和 Skills。

## 验收标准

- [x] 上下文详情与具体调用和尝试关联，实际采集人格、职责、任务和显式上游输入的来源及内容。
- [x] 知识库、Skills 及已有注入追踪支持的追加、替换、裁剪记录接入同一阅读入口。
- [x] 配置预览与实际送入模型的内容明确分开；记录不可获得或被截断时说明，不拿配置摘要冒充采集证据。
- [x] 同一 Agent 的不同调用、并行成员及重试记录互不覆盖，来源可以展开核对。
- [x] 实际下游上下文只包含明确选择的上游数据，不因界面能查看完整过程就自动注入模型。
- [x] 沿用现有过程、文件和账户权限，能回答人工请求不代表能读取所有者的全部上下文配置。
- [x] 模型／远端执行器不提供的字段保持可解释的缺失状态。
