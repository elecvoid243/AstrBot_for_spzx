## 构建内容

用户配置目标、协调者和预设成员后启动自主团队，由协调者在允许角色中动态分配任务并交付结果。

## 验收标准

- [x] 协调者和预设角色可直接配置或固定引用模板，沿用同一资源、默认模型及覆盖语义。
- [x] 协调者只可在配置的角色范围内创建成员实例和安排任务，不能自由生成角色、资源配置或权限。
- [x] 实际成员执行使用冻结后的有效资源与职责，不把发起聊天的默认模型／人格作为隐藏回退。
- [x] 团队结果、成员状态、现有产物和用量可从公共运行接口读取并在团队运行入口查看。
- [x] 成员实例、任务及调用归属稳定，同名成员和重复使用模板不会串用结果。
- [x] 现有实例、并发、迭代、深度与预算限制继续校验；不增加普通 WebChat 会话创建或跨会话工具。
- [x] 自主团队的创建、版本保存、启动和恢复接入新资源格式，相关 UI 与行为说明同步。
