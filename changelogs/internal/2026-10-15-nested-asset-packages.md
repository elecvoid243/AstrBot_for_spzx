# Nested asset packages and immutable upgrades

- Export the complete pinned role, loop, team and workflow closure. Format 2 carries child definitions; existing format 1 single-layer packages remain supported.
- Validate all references, contracts, return tasks, depth, cycles and iteration limits before matching resources. Install the whole closure and its reviewed local bindings atomically, or retain affected entries pending configuration.
- Reuse identical versions, append upgrades under the same local asset identity and reject conflicting asset or role content under an existing identity/version. Existing runs, pinned children, artifacts and approvals retain their original snapshots.
- Keep the selected imported entry as the default local version when its closure pins another version of the same asset; every pinned reference still targets its exact installed content.
- Re-preview reviewed dependencies in their normalized slot namespace. Check child loop and member-instance limits against effective role/profile values before confirmation; incompatible configurations remain pending instead of appearing ready.
- Match reviewed choices against every reused closure installation. Retain compatible saved choices, apply uniquely matched replacements for unavailable resources, and require explicit confirmation when compatible saved choices differ; ambiguous or missing resources remain unready. Confirmation writes the reviewed bindings without rewriting old run snapshots.
- Preserve unresolved saved bindings when pending imports include the dialog's copied preview proposals; matched partial selections can still be saved.
- Keep pending upgrades and independent packages from imposing their graph limits on valid installed versions or pinned children. Launch validates the selected definition while preserving portable role resource requirements.
- Preserve imported portable dependency declarations when exporting a newly authored parent, including explicit unused resources, model capabilities, tool schemas and unspecified optional constraints. Keep distinct logical choices even when they share one local resource; derive task provenance from current selections across local asset versions without copying bindings or unused task requirements.
- Check each terminal member's depth on every reference path and resolve inherited profile depth before confirmation. Imported entries, including later local versions, validate their current full closure before readiness or a new graph run; ordinary local entries retain runtime call-boundary checks. Only the actual coordinator's role limit bounds its child calls. Independently valid child entries keep their own depth context.
- Keep absolute placement in shared-definition depth validation, so a shorter path cannot hide an invalid descendant on a deeper path and reference ordering does not affect acceptance.
- Keep the original attempt waiting when pause wins between execution admission and usage reservation. Continue reserves and delivers the pending call once; cancellation, stale execution and quota denials retain their existing boundaries.
- Preserve imported resource compatibility requirements across local role edits and check current authorization before further execution. Packages carry no credentials or local authorization, run no scripts and do not install plugins or services. Historical HTML demo exports have no production compatibility promise.
- Keep task-only resource requirements within their exact asset closure, rebase slots with their reviewed bindings, and isolate installations with different effective requirements. A parent-only override upgrade reuses unchanged children; explicit unused and legacy requirements remain enforced. Task-supplied prompts stay with each task without replacing role defaults with the first parent's tool choices.
- Entry mapping: **Workflow Assets → Export workflow JSON / Import workflow package → Export asset JSON / Import asset package**. The workspace and **Edit Asset / Start Run** entries remain in place; the labels now cover complete nested assets.
- 入口对照：**工作流资产 → 导出工作流 JSON / 导入工作流包 → 导出资产 JSON / 导入资产包**。工作区及**编辑资产 / 启动运行**保留；新文案覆盖完整嵌套资产。
