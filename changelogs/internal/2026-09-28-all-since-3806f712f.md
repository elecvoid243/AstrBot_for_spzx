### 修复

- Agent 工作胶囊不再吞掉仍待作答的交互选项框：折叠的回复区会隐藏选项框，现在待作答的消息保持展开、作答后照常折叠。 (`bb5aa3865`, `052bc6226`)

- 一轮对话只落一条历史记录：中途需要作答时曾多存一条，刷新后同一轮被拆成多个气泡；现在首次建行、后续追加，统计 / 文件变更 / 引用按整轮取值（此前已产生的旧记录不会回溯合并，需重启后端）。 (`ebac3152d`, `c2f091e07`)

- 文件变更摘要卡两处修补：子代理改动的文件也计入主 Agent 的变更列表；被删除或读不到的文件明确标注，而不是静默跳过。 (`e68cb8a12`, `25cc140be`)

- 本地 Shell kill 目标解析：按名称指定目标时先解析再判断是否误伤自身，非本机目标的拒绝提示更清楚。 (`eb7d63856`, `e1cfc90a0`)

- 切换「本地 Shell 类型」不再让系统配置保存失败：此前重启后第一次保存成功、之后必失败（面板报错但文件其实已写入），现在只终止旧类型的 shell 会话、保留当前会话。 (`6fcf2eee1`；相关的上游合并 `f9488d514`)

- Git Bash 托管 Shell 会话的 poll / interrupt / terminate 不再挂起或报错：终止此前可能卡住约 110 秒、进程被杀后还会抛异常，现改为有硬上限的等待，秒级干净返回。 (`d3969c9d9`, `8b374284a`, `0514ddfb1`, `fecd7811e`, `d1dffdd63`, `56e7e5455`)

- 已作答的交互选项框不再被重新贴到对话尾部：翻过历史后，过期的框会被当成待作答追加到最新一条消息上；现已跳过已作答 / 已取消的框。 (`503347707`)

- SubAgent 追加输入框只在卡片展开时出现，收起态不再常驻。 (`249d4936b`, `25b71784d`)

- Python 工具超时修正：`astrbot_execute_python` / `astrbot_execute_ipython` 被列入 `tool_call_timeout_exclude` 后不再被全局超时封顶，只认模型传入的 timeout，缺省值 30s → **60s**。 (`8a1be2d05`)

- 项目加载完成后「当前分支」不再需要手点刷新：此前一次取数失败后再无自愈通道，现会自动重取并带退避重试；按钮文案区分加载中 / 取数失败 / 真正 detached 三种情况，只有后端确实报了 detached 才显示「detached HEAD」。 (`d1dbddd50`)

- 终止或回收 shell 会话不再可能卡住：取消不落地时也会在硬上限后放弃等待，而不是把调用方楔死。 (`bb660a59a`)

- pythonw 下终止 shell 会话不再闪出一个黑框（子进程不再被分配到可见控制台）。 (`ad06d3d18`)

- 会话状态推送不再被系统流门禁拦掉：指示器不会因为这类消息天然没有 `message_id` 就漏更新。 (`71273721f`)

- 终止 shell 会话发给 agent 的系统通知去掉内部 `[ChatUI]` 前缀，不再把实现细节端给模型。 (`01ba235ac`)

- 发送后卡在「思考中…」不再需要刷新页面：整轮一个事件都没收到时（后端以 200 + JSON 返回业务错误、空响应体，或本轮结束早于订阅建立）占位气泡会一直转圈；现在会显示真实原因、丢弃空占位并按会话历史重新对齐，顺带把被丢掉的回复补回来。 (`2d242a037`)

- 跑测试不再改动你本机的配置文件：测试夹具此前先按默认路径构造配置对象、再替换路径，于是每跑一次测试就把真实的 `data/cmd_config.json` 回写一遍并不断多出新段落；现在构造时就指定临时路径。 (`bd9e2c24e`)
