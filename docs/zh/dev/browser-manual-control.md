# 浏览器人工控制协议（H01/H02）

完整字段与连接生命周期见 [英文协议](../../en/dev/browser-manual-control.md)。

- 使用 Dashboard 登录态调用 `POST /api/v1/plugins/browser-control/session`，
  请求仅含 `chat_id`、`generation`、`browser_session_id`。宿主校验聊天所有权、
  插件启用状态及审计标记，返回 15 秒内有效、一次性使用且绑定账号凭证版本的票据。
- 在返回的同源 WebSocket 建立后 5 秒内发送 `{ticket}`；凭证不得放在 URL 中。
  服务端确认 `operation: acquire`、`status: applied` 后才允许点击。
- `control_mode` 区分 `agent`、`acquiring`、`human`、`paused`；
  服务端 `control_epoch` 与观测帧 `sequence` 独立。点击携带连续 `input_id`、
  CSS 视口坐标和当前图片的标签页、文档、视口、滚动位置，运行时再次验证真实目标。
- 重复最后一个输入编号仅返回已记录的确认，不重复执行；旧编号、跳号和旧代次拒绝。
  不提供任意 CDP、脚本执行或自行指定其他目标的代理。人工控制期间复用一致性截图路径，
  以不超过每秒四帧的 JPEG 经原 SSE 通道反馈静态页变化；画面和控制状态分别保留，
  避免状态消息覆盖唯一的新画面。只读模式继续兼容原有观测流。
- 每 5 秒发送心跳；宿主 15 秒无消息关闭连接，私有运行时 30 秒无续约撤销控制。
  断连或隐藏面板立即停止输入并保持暂停，不自动启动 Agent。
- 明确发送 `release` 后才交还；先清除旧元素索引并重新观测实际页面，再开放 Agent。
  浏览器、标签页和登录态保留。运行中的本地 Agent 进入可恢复的 `PAUSED`，
  等待不占普通工具超时，不持续请求模型。接管先关闭准入，取消或有界等待在途动作及已派发
  的页面事件；确认静止前不开放人工输入，失败时保持暂停。旧模型结果和批次剩余调用失效，
  工具调用与真实中断/未执行结果逐项配对。交还后的标签、页面和交互元素观测经可信宿主
  加入原轮次模型上下文，再决定下一步，不重放旧点击。取消、停止、关闭和禁用仍是终止行为；
  交还不会复活已结束的轮次或创建新任务。
- 每条输入重新校验账号、聊天与插件；私有运行时统一校验 Agent 和人工执行准入。
  旧观察客户端、停止与关闭行为保持兼容，旧插件保持只读。

H03–H05 在此身份、代次、顺序确认与明确交还约定上继续扩展。
