## Added

### Chat & Composer

- Registered enabled skills as `/` commands in the composer palette: typing `/` lists session-effective plus globally enabled skills (the "show all" toggle widens it to every skill on disk); selecting one queues the one-shot guidance nudge and strips only the trigger token, so text typed after it is preserved; typing `<prefix><skill> ` auto-queues without waiting for the menu. (`95ddc04d8`)
- Fixed the skill palette clearing the typed query: picking `writing-plans` after typing `/wr` now removes `/wr` instead of leaving it in the composer (the token is stripped as a query, no longer compared against the full skill name). (`1fdb064aa`)
- Queued-skill chips render in the wrapping badge row above the composer for both load paths (`/` palette and the "+" menu), so long/multiple chips are no longer clipped inside the composer. (`154b19b27`)
- The skill guide menu now stays open when the pointer leaves it and gained an explicit close button. (`3e74eca92`)
- Chat history loads in paginated windows (backend pagination endpoint + incremental frontend loading) instead of pulling a whole session at once. (`6112abc7e`)
- Scroll-strip markers can be jumped by session-wide index. (`0da3fc3b0`)
- Subagent run cards keep a sticky collapse button pinned above the scroll viewport while a long run is streaming. (`f0d38766c`)

### Dashboard

- Conversation workspace filter gained a "Show webchat conversations" switch (webchat stays excluded by default; toggling re-fetches with a debounce, resets the page and participates in clear-filters), and the history preview now keeps persisted reasoning parts. (`dbf2414a4`)
- The announcement bar re-fetches every 15 minutes so updates appear without a page refresh; transient poll failures keep the last known announcement. (`32da1c4f1`)
- Git history improvements: hash search highlighting with a dedicated no-match state, a grouped ref picker, commit-message and grep filters, tag parsing and tag chips rendered in history rows. (`6fe93d92e`, `3adbdf77b`, `def47be21`, `99f9de299`, `156b29972`)
- Codegraph services popover reports "已加载" whenever the MCP is running (success dot), even without a default project; the Codegraph manager dialog was split into two sub-pages — "初始化 / 更新" (new silent `POST /spcode/codegraph-init`, `codegraph init`, auto `--force` rebuild) and "设为默认目录" (`POST /spcode/codegraph-set`) — sharing the path field and history. (`5b7be9685`)

### Core & Tools

- Tools listed in `tool_call_timeout_exclude` now wait until they return on their own; the hardcoded 3600 s cap was removed and timeout errors report the actually applied timeout. (`13a3eb53a`)

## Fixed

- Suppressed child console windows at the `CreateProcess` layer, covering spawn paths that bypass `subprocess.Popen` (notably the Windows multiprocessing spawner under `pythonw.exe`). (`6c466f560`)
- Guarded managed local shell sessions against self-kill in `exec_managed()` and `write_session()`, and broadened the kill-invocation detection beyond a single `kill <pid>` pattern. (`2834e40ce`)
- Git log / history view: no re-scroll on polling ticks, deep-link focus restored when data arrives, stale focus and no-match empty state cleared, real group headers rendered with the ref model kept as a string, tag list kept across branch mutations, nested buttons removed from history rows, and the git-log fetch gated on the History tab with filter/selection reset on worktree switch. (`d15e2f5db`, `7f3dcfcb0`, `6b99ea4e2`, `908d74a16`, `b55c15265`, `f7f2e6632`, `35d970023`)
- Reset the terminal history index after submitting a command. (`056684d38`)

## Maintenance

- Added the `extractApiError` dashboard utility and the `sseReader` / `useMemberRunStream` composables (infrastructure introduced for Agent Teams). (`d003a28c7`, `e3b8e9775`)
