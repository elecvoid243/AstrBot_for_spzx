## 构建内容

用户在画布配置条件与并行分支，运行只等待实际进入的所有成功分支，并清楚看到局部失败及受影响路径。

## 验收标准

- [ ] 条件和并行汇合节点使用可辨识卡片和明确控制连线，条件字段通过已有输入选择器配置。
- [ ] 汇合仅支持 ALL：本次实际进入的分支全部成功才继续，条件未选中的分支不参与等待。
- [ ] 没有任一分支成功即可继续或竞速模式；条件跳过和失败不能被混成成功。
- [ ] 一个分支失败只阻塞该路径及依赖它的下游，独立分支继续并保存成果。
- [ ] 汇合等待原因、跳过、失败与未开始在运行数据和界面上区分，不能仅标为含混的待处理。
- [ ] 定义保存、重开、运行推进及结果读取沿用同一图契约；错误定位到节点与分支。
- [ ] 并发或重复调度通知不重复启动已经认领的同一步骤。

## 测试决策

沿用已有图服务的条件跳过和独立慢分支先例，用可控屏障验证汇合、局部失败、重复通知和最终输入，不依赖固定等待时长。
