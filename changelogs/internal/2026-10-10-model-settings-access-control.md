# Model Settings Shortcuts and Access Control

- Add model settings gears beside explicitly selected models and in model/fallback menus. Saving model settings immediately affects every profile using that model; profile selection and fallback order remain unchanged. (#10321)
- Order profile sections as AI, Platforms & Messages, Access Control, Plugin, and Extensions. Configuration keys and default values remain unchanged.

| Previous location | Current location |
| --- | --- |
| AI Configuration / Platform Configuration / Plugin Configuration | AI / Platforms & Messages / Plugin |
| Platform → General → Administrator IDs | Access Control → Administrators → Administrator IDs |
| Platform → Whitelist | Access Control → Whitelist |

## 中文

- 模型选择器旁及模型、回退模型菜单内新增设置齿轮。保存模型设置立即影响引用它的所有配置文件，不改变当前模型选择或回退顺序。 (#10321)
- 配置分区顺序调整为 AI、平台与消息、访问控制、插件、扩展功能；配置键和默认值保持不变。
