## 构建内容

用户导出包含角色和嵌套资产的新版包，在另一套资源标识下选择本机资源并导入可运行资产。

## 验收标准

- [ ] 导出包表达固定资产闭包、真实资源类型和要求，不包含逻辑槽位、别名或运行期绑定表。
- [ ] 导入预览逐项展示来源需求和本机实际资源选择，明确缺失或不兼容资源。
- [ ] 资源匹配完成后保存目标实际引用；源实例 ID 不被直接当成本机同一资源。
- [ ] 固定版本、嵌套依赖、内容一致性、权限与重复依赖复用规则保持有效。
- [ ] 一次导入失败不会留下半完成资产或错误绑定，重复导入有明确结果。
- [ ] 导入的角色、工作流和自主团队可通过正常入口执行；不另造包专用执行通路。
- [ ] 旧槽位包或不支持的格式明确拒绝，不自动迁移或兼容执行。

## 测试决策

在两个真实临时资源目录与数据库间导出／预览／导入／运行，观察实际模型和资源；覆盖嵌套引用、缺依赖、越权、事务失败和旧格式拒绝。
