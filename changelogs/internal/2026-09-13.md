# Internal Changelog — `all` branch since `c0ddbfd08`

### 新增

#### 聊天与输入框

- 思考强度档位默认值调整为Deepseek格式（低 / 高 / 最高，默认预选「最高」）；档位字段仍可自定义。 (`d1e9e96a8`)
- 输入框草稿按会话持久化：未发送文本按 session id 存入 localStorage（上限 50 条，最旧裁剪），切换会话、页面跳转、整页刷新后草稿不丢；无会话落地页输入的文本在新建会话时自动带入。 (`0dcbe54ee`)
- Agent 工作折叠胶囊：流式期间思考 / 工具块 / 中间输出照常实时渲染，回合结束后把最终回复之前的全部工作折叠为一个「已工作 N 秒」胶囊，仅保留最终回复，点击重新展开完整工作轨迹；交互选项不折叠。 (`d2800b818`)
- 待处理追问队列视觉优化。 (`cbc928c72`)
- Token 圆环显示缓存命中率。 (`6888ed5e3`)
- 回合结束文件变更总结卡片：Agent Loop 完全结束后，在最终回复下方按文件聚合展示本轮净 diff（同一文件多次编辑合并为最终结果），支持查看 diff / 在磁盘打开 / 单文件撤销（两步确认 + 内容校验冲突保护）。文件工具将每次修改记录进 `AstrAgentContext.extra["changed_files"]`，runner 收尾时基于编辑备份引擎的首个基线备份计算净 diff 并以 `file_changes` 事件推送，随消息持久化；write 工具补齐覆盖前备份。 (`0c98a33f6`, `99c7498bd`, `c92e1d3d1`, `35714ec7c`, `e9c48061e`, `c27a0b96e`, `e8fcdec24`)

#### Dashboard

- Git 提交对话框支持可选 tag：提交成功后按接口返回的精确 SHA 打 tag（需spcode_toolkit同步更新）。 (`5aba4613f`)
- Git diff 侧栏路径条新增「在磁盘打开」按钮。 (`bfc846067`)

#### 核心与工具

- 主 agent runner 按会话记录每次聊天请求指纹（model、逐工具 schema 哈希、逐消息规范化 JSON 哈希、system 原文；subagent 请求跳过，LRU 限 64 会话），供 compact 插件等同前缀流程对比定位 provider 前缀缓存 miss 的精确位置（工具段 / system / 具体历史消息）。 (`8ea8216db`)
- 添加工具权限：设置一个`denied_tools` 门，被吊销工具的 schema 保持 payload 可见（不破坏缓存），但拒绝执行并给出引导性语句。提供给 max_step 强制收尾轮 / plan 只读 / subagent 编排类工具的使用。 (`614f4c9ed`, `6ef62f9fa`)

### 修复

- 本地运行时的工作区路径写入位置从system prompt改为 `<system_reminder>`，以防止分支会话切换工作区时缓存miss。 (`415c49d10`)
- 修复子代理未指定 provider 时，fork 模式被降级为普通模式，优先取主 agent runner 实际使用的 provider。 (`e030c9514`)
- 修复快照恢复时聊天历史顺序错位的问题。 (`b74fa2ee7`)
- 修复聊天历史的滚动条标记跳转到错误位置的问题。 (`59951e8fc`)
- fork 模式子代理继承主 agent 的 `llm_params`，消除把该参数渲染进 prompt 的后端（如vllm）上从 token 0 分叉，缓存不命中的问题 (`ca60441ce`)
- 内置压缩（`LLMSummaryCompressor`）的摘要请求附带与聊天请求相同的工具集和 `llm_params`，使摘要请求轮可以命中缓存。 (`f2389d7d9`)
