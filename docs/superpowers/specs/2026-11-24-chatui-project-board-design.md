# ChatUI 项目待办看板

从 ChatUI 左侧栏选择项目后，项目页默认显示「会话」。用户可在同一项目标题下切换到并列的「待办看板」，管理「待办」「进行中」「已完成」三列。管理员点击托盘提醒时直接打开对应项目的看板并定位到卡片。会话工具栏的 Todo 指示器继续展示当前 Agent 的执行清单。

## 侧栏快捷入口与拖拽

在 [ProjectList.vue](../../../dashboard/src/components/chat/ProjectList.vue) 的每个项目行中，将看板图标放在「＋ 新建会话」旁边。点击图标时，以该行项目为目标打开看板浮窗，保留用户当前正在查看的会话或项目。再次点击同一项目的图标，唤起已打开的窗口。

浮窗参照 [ShellSessionWindow.vue](../../../dashboard/src/components/chat/ShellSessionWindow.vue)：标题栏显示项目名，可用鼠标拖动窗口并置于其他面板上层。浮窗没有遮罩，窗口外的侧栏、会话和输入框可以继续操作。关闭浮窗后保持原页面。

项目页和浮窗操作同一张看板。在任一入口，都可以拖动卡片到目标列改变状态，也可以拖到同列另一张卡片前后调整顺序。拖动时高亮可放置的列，释放在看板外则保留原状态。用户拖入「已完成」等同于手动确认完成，停止后续提醒。卡片详情保留状态选择，供键盘和触屏用户操作。

## 从待办新建会话

「发送给 Agent」的会话选择器提供已有会话和「为此待办新建会话」。选择后点击「新建并发送」，在卡片所属项目创建会话，默认用待办标题命名，并将标题和描述作为第一条任务消息发送。关闭选择器或仅保存卡片时不创建会话。

目标会话确认接收后，卡片可直接打开该会话，处于「待办」的卡片移至「进行中」。如果会话已创建而消息发送失败，重试时沿用该会话，卡片在任务送达前保留原状态。

## 视觉验收

以现有 [ProjectView.vue](../../../dashboard/src/components/chat/ProjectView.vue) 为准。切换视图时，保留同一份项目标题、图标、描述和工作区摘要，内容左缘与会话列表对齐。看板工具栏显示项目完成进度、搜索和「新建待办」。每列按内容决定高度，达到可视高度后仅滚动列内卡片。列标题支持拖拽排序，顺序随项目保存。拖拽过程中相邻卡片平滑让位，靠近边缘时自动滚动，松手后卡片滑入占位处。

点击卡片时，详情从卡片的位置展开。用户可增删、改名、排序和勾选子任务，为卡片设置多个带名称的颜色标签。卡面显示子任务完成数和标签。保存前的编辑仅存在于当前弹窗，取消后保留已保存的卡片内容。

视图切换优先复用 ChatUI 的 [SpSegmentedControl.vue](../../../dashboard/src/components/chat/SpSegmentedControl.vue)。卡片继承 ChatUI 的字体、主题色和悬停态。列名写明状态，颜色仅作辅助。实施时在真实项目页中并排核对亮色和暗色效果，并在窄屏验证卡片操作。
