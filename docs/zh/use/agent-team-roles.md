# Agent 团队角色模板

打开 **更多功能 → Agent 团队 → 角色模板**，点击 **新建角色**。角色模板保存职责与能力需求，不创建成员聊天会话，也不直接启动运行。

1. 填写角色名称和说明。在 **职责与提示词** 中输入内嵌职责提示词，或填写人格逻辑槽位并绑定本机人格，选择继承人格提示词。
2. 在 **模型** 中选择继承的本机配置档案，填写模型逻辑槽位并绑定本机模型。可声明 `tool_use`、`image`、`audio` 能力；本机模型没有声明所需能力时，预览显示不兼容。
3. 在 **工具、技能、知识库** 中选择继承、全部禁用或局部覆盖。局部覆盖时输入逻辑槽位名称并按 Enter，再为每个槽位选择本机资源。逻辑槽位表达定义的需求，本机绑定记录当前机器的资源身份。
4. 在 **实例与执行限制** 中填写实例数、并发数、步骤、迭代、嵌套、工具超时和上下文长度。留空继承。独立单任务运行会冻结有效配置；支持的行为与限制见[工作流说明](./agent-team-workflows.md)。
5. 点击 **预览配置** 查看最终有效值、继承来源和覆盖值。缺失、歧义、已禁用或不兼容资源会显示字段路径；点击路径打开对应分组。修改后需要重新预览。
6. 点击 **保存角色**。允许保存待配置模板；卡片用文字显示 **待配置**。编辑已有模板时点击 **保存新版本**，历史定义和历史绑定均保留。通过 **查看历史版本** 重新打开旧版；以旧版内容编辑并保存仍会创建一个新版本。

内嵌提示词属于可移植定义，预览明确显示可移植提示词内容。人格引用仅声明逻辑依赖，其本机提示词不会嵌入定义。本页不提供完整资产包导入导出；该能力由后续任务交付。

工具与技能的可用范围取决于所选配置档案的已启用插件，技能还遵守该档案的运行环境。局部覆盖仍遵守人格的工具与技能允许范围；未显式绑定人格时，这些能力继承配置档案的默认人格。被人格排除的绑定会显示字段诊断，不会被标为就绪。内置工具沿用现有 Agent 主管道中的配置档案可用范围。

## 旧入口与本票新增入口

| 原有入口 | 本票入口与用途 |
| --- | --- |
| Agent 团队 → 成员 | 保留旧成员配置和长期会话；未自动迁移为角色模板。 |
| 新建可复用角色 | Agent 团队 → 角色模板 → 新建角色。模板独立于旧团队和成员。 |
| 工作流编排、运行监控、历史 | 保留旧入口；新版单任务通过工作流资产引用角色版本，在独立运行中查看。 |

角色接入新版单任务的步骤见 [单任务工作流资产与独立运行](./agent-team-workflows.md)。新版运行冻结角色及有效配置，调用检查点恢复和更复杂的编排仍由后续任务交付。

配置预览使用当前本机资源，历史定义不会静默改用默认模型。资源后来被删除或禁用时，重新预览会定位问题。本票不声称完成父规格中运行恢复、迁移或全工作台的验收。
