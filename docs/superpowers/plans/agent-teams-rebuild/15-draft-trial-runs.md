## 构建内容

用户选择草稿试运行范围和上游测试数据，真实执行所选步骤，并在独立测试记录中检查结果。

## 验收标准

- [ ] 入口支持单节点、从选定位置开始的局部流程和完整流程，实际执行范围与界面选择一致。
- [ ] 每次试运行冻结草稿内容、范围及输入来源，后续草稿编辑不影响已启动测试。
- [ ] 上游输入可选择已有运行的固定结果或显式填写测试数据，缺失和类型不符在启动前指出。
- [ ] 所选步骤真实使用已配置模型和工具；测试输入只替代相应上游数据，不默认为缺失步骤成功。
- [ ] 结果、产物、用量和过程作为独立测试运行保存，正式运行及原上游结果不被覆盖。
- [ ] 与正式执行共用权限、能力、预算、暂停／取消和恢复规则，不复制第二套调度内核。
- [ ] 界面明确所选步骤会产生真实调用及可能的外部效果，不把重放历史或修改输入描述为撤销效果。
- [ ] 支持当前首批节点组合，局部范围不满足依赖或作用域约束时给出可解释校验。

## 测试决策

通过真实运行公共接口分别执行三种范围，使用可观测模型／工具调用账本断言实际执行的步骤、固定输入及独立结果；覆盖无效局部范围与权限失败。
