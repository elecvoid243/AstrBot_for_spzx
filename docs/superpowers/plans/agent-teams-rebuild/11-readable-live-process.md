## 构建内容

用户启动一个 Agent 后，在正式运行工作台持续看到真实回复、思考及工具卡片，并重新打开同一运行读取已保存过程。

## 验收标准

- [x] 运行页建立任务／Agent、过程、待办／产物的信息结构，执行图保留为总览入口；使用实际运行数据而非 HTML 示例。
- [x] 执行管线发出的正文、实际思考、工具开始／参数／进度／结果／错误到达公开过程读取和前端展示。
- [x] 事件从首次实现即保留稳定的根运行、作用域、任务、成员、尝试及调用／分段归属，不依靠显示名称推断。
- [x] 单 Agent 的实时片段与最终消息归并，不把完整终态文本追加为重复回复；已结束运行可读取保存内容。
- [x] 复用 ChatUI 的 Markdown、思考折叠、工具卡片和文件预览能力，不嵌入完整普通聊天路由，也不默认展示整块 JSON。
- [x] 未提供思考或工具内部进度时明确范围，不生成假过程；执行状态由后端事实决定，不以流结束判定成功。
- [x] 后台更新不卸载整页或重置输入与滚动意图，切换离开页面不终止执行。
- [x] 沿用并扩展现有事件／持久过程与公开读取边界，文本有界批量写入，重要执行边界及时保存。
