# 更新日志 — 2026-11-02

接续 [2026-10-13 更新日志](./2026-10-13-all-since-fe5204e97.md)，覆盖 `all` 分支中 `cf32edf43` 之后至 `55b2ee13f` 的改动。相关提交按最终功能归并，不单列开发、测试及中间方案。

## 新增与改进

- 管理员的项目侧栏“+”和输入框项目 chip 共用路径加载页面：原“自定义路径”迁移至该页面，新建时不再提供“项目共享工作区”及“按会话分开”；加载后会话自动归组，chip 中可选择“不在项目中工作”。

- 新增并完善 Agent Teams 多智能体工作台，支持角色与团队配置、独立页面编辑可视化工作流、草稿试运行、人工审批、运行过程查看及资产导入导出。
- 新增多用户 ChatUI，支持独立账户、会话、项目、附件与配置选择，以及账户管理和完整备份恢复。
- 新增宿主文件浏览与聊天文件引用，支持文件预览、编辑、重命名、移入系统回收站和在宿主机打开；未加载项目时默认浏览当前会话工作目录，并放大目录选择窗口。
- 新增工作台网页预览和 Agent 浏览器：网页预览支持多标签页、自适应侧栏宽度和全屏；Agent 浏览器支持全屏查看、实时观测，以及在需要时接管操作、拖动页面元素并交还 Agent。
- 完善侧边聊天与分支追问，支持保存和重新打开侧聊、独立配置及可调宽度的面板。
- 新增补丁式文件编辑工具，支持批量修改、预览和回滚，并默认使用补丁模式。
- 内置 `/compact` 上下文压缩、交互式选择和技能引导，减少插件依赖；增加新标签页打开的 Skill 商店入口。
- 完善文件审阅，支持整文件差异、逐行评论和直接发送反馈；优化 Git 变更树、大型差异加载与工作树切换。
- 支持按项目配置文档快捷目录。
- 在聊天输入菜单增加目标任务入口，改进目标进度、完成提示、思考强度与上下文用量展示；优化窄屏布局和深色模式下的按钮可见度。
- 支持在 Agent 执行工具期间发送包含图片的追加消息。
- 支持在 Dashboard 公告中展示图片。
- 调整插件市场的源选择：选中自定义源时不再主动拉取官方源，切回默认源后恢复。

## 修复

- 修复流式回复、历史分页、切换会话及打开文件引用时的滚动跳动和阅读位置丢失。
- 改进长对话和工具调用的稳定性，修复上下文压缩、取消与恢复、输出长度控制及工具结果关联问题。
- 修复流式图片回复中的内部标记泄漏、追加消息重复，以及部分回复和工具信息丢失或显示顺序不正确的问题。
- 修复 Agent 浏览器画面闪烁及窄侧栏显示问题，断线后可手动刷新重新连接；改善后台任务结束后的状态更新。

> Agent Teams 已调整为新的资产与运行工作台；旧数据不会自动迁移，旧入口与新入口的对应关系见 [使用说明](../../docs/zh/use/agent-team-workflows.md#旧入口对应)。
