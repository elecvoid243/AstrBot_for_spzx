# Controlled member communication

- Members can inspect recipients and send durable questions, feedback and exact artifact references within their current run and scope. Communication preserves coordinator authority over creation, dispatch and completion.
- Stable delivery identities deduplicate retries. A recipient consumes messages at a serialized model boundary, with its context and consumption position committed atomically. Stale attempts and executors cannot deliver or consume messages.
- Task process details show delivery and consumption correlations and read complete pinned artifact versions. Long references wrap on narrow screens.
- Entry mapping: communication previously appeared only in tool results; use Agent Teams → Independent Runs → View Run → select task → Saved member process → Member messages. English and Chinese instructions and production screenshots are updated.
